# Qt Object Tree Demo

Лабораторная работа №2 по кроссплатформенному программированию.
Демонстрация дерева объектов QObject, работы родительских связей и автоматического удаления дочерних виджетов.

## Возможности
- Создание виджетов с явным родителем.
- Логирование создания и уничтожения объектов через qDebug().
- Демонстрация удаления панели (deleteLater) вместе с дочерними элементами.
- Демонстрация смены владельца виджета через setParent().
- Демонстрация отвязки виджета (setParent(nullptr)).

## Сборка
1. Открыть проект в Visual Studio 2022 с Qt VS Tools.
2. Выбрать конфигурацию Debug.
3. Собрать (Ctrl+Shift+B) и запустить (F5).
4. Наблюдать за логами в окне "Вывод" (Output).

## Примечание
Текст интерфейса и логов на английском языке во избежание проблем с кодировкой MSVC.
